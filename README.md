**SpendWise**
SpendWise is a console-based expense tracking application that helps users record, review, and analyze their personal expenses through a simple menu-driven interface.
The application allows users to add expenses with an amount, category, and description, and provides useful summaries and search capabilities for managing expense records.

**Features**
Add and store expenses
View complete expense history
Calculate total expenses
Identify the highest expense
Identify the lowest expense
Filter expenses by category
Calculate total spending for a specific category
Search expenses by description
Case-insensitive category and description searches
Input validation for expense details
Support for up to 100 expense records

**Expense Information**
Each expense contains:
Amount — monetary value of the expense
Category — such as Food, Travel, Shopping, Bills, etc.
Description — details about the expense

**Example**
=== Welcome to SpendWise ===
1. Add Expense
2. View All Expenses
3. View Total Expenses
4. View Highest Expense
5. View Lowest Expense
6. View Expenses by Category
7. Search Expense
9. Exit

SpendWise provides a lightweight way to keep track of daily spending and quickly understand where money is being spent.
